# 备课工坊

Go + Vue + PostgreSQL/pgvector + Python 的教育智能体本地原型。当前可运行版本以课件为主，支持真实PPTX文件与隔离Manim生成的静音MP4。产品约定见 [SPEC.md](SPEC.md)。

## 本机运行

本机已安装依赖并构建前端。访问 **http://127.0.0.1:8080**。

账号：`teacher`（教师）、`admin`（企业管理员）、`low`（8积分，用于不足额度验收）、`other`（另一企业教师）。初始密码取本地 `.env` 的 `SEED_PASSWORD`。本地初始化文件设置的是开发演示密码；不用于公开部署。

`SEED_PASSWORD`只在账号首次创建时生效。已有账号的密码保存在数据库中，修改`.env`或重启都不会覆盖它。需要同步某个演示账号时，在项目目录运行`./scripts/reset-password.ps1 -Username teacher`（可换成admin、low、other）。脚本读取当前`.env`，只重置指定账号并撤销其旧登录会话，作品、额度和其他账号不变，无需再次重启。

```powershell
# 在 D:/tools/harness/edu-agent 中
powershell -ExecutionPolicy Bypass -File scripts/start.ps1
# 首次需要构建动画镜像时
powershell -ExecutionPolicy Bypass -File scripts/start.ps1 -BuildAnimation
# 停止由脚本启动的进程；保留数据库和数据
powershell -ExecutionPolicy Bypass -File scripts/stop.ps1
```

脚本要求 Docker Desktop 已启动，以及 Node 22+、Python 3.13+、Go 1.26+。本机 Go 在 `work/toolchain/go/bin`，脚本优先使用它。其他机器需自行安装 Go。首次安装复制 `.env.example` 为 `.env`，修改JWT密钥与初始密码。

数据库用 `docker compose up -d --wait db` 启动，宿主机端口55432。默认Python解析/PPT服务作为本机进程运行；也可用 `docker compose --profile render up -d --build renderer`，不要同时占用8000端口。

Go作为宿主机上的可信调度器调用Docker CLI，生成脚本只能进入单任务沙箱容器。没有把Docker socket挂入生成代码容器。当前没有“一条Compose命令包含所有服务”的部署方式。

## 已有功能

- 新建课件采用对话协作工作台：先实际生成前三页，逐页编辑、评价与审核后确认，再生成剩余页面；全套每页审核通过后完整交付。未确认前不会生成隐藏完整课件。旧作品保留原工作台。
- 对话支持讨论或修改当前页；页面与回复支持点赞/点踩，点踩需原因、撤销本页审核并进入后续修订约束。反馈不是模型训练、不扣教师积分。草稿对话不额外扣业务积分，已交付单页AI改写成功5积分；各次模型请求仍可能产生供应商费用，每作品最多60条对话。
- 本机Office输出实际PPTX页面截图，预览PPTX也可下载。其它无Office环境明确显示布局示意。已有模板、教案、图表/公式/配图编辑、完整阶段增删复制/排序、来源、历史内容/备注查看与免费恢复、课件转动画均保留。使用方法与验收范围见 [课件协作工作台](docs/courseware-studio.md)。

- 点击左下角头像/姓名进入个人账户（手机端为顶部“账户”）：修改显示名称或登录密码。登录账号保持不变；改密需验证当前密码，成功后撤销所有旧会话，作品和成员额度不变。
- 课件遇到表格/图解/图表/配图组合冲突时自动拆页并保留内容，初始8–20页可能增加续页（成品最多100页）。已中断课件显示“待继续制作”，可点击“继续制作”；有效草稿优先复用，无有效草稿则重新研究。原任务释放预留、不扣款；续作只预留一次20积分，交付成功后结算。外部服务故障仍可能中断，不保证任何条件下100%成功，也不以样例冒充真实交付。
- 多企业登录切换，成员权限、停用、新建账号；成员独立套餐和积分。
- 课件自动修复：超行/超列表格拆为续页并重复标识列；过长单元格转为逐项记录，正文按原文分页，长标题和表头完整原文保留在备注。缺失数据明确标注，不补造数值。首次生成、确认、编辑导出、版本恢复和单页改写共用排版修复；实际PPTX渲染通过后才交付。
- 模型结构错误、输出截断、临时网络或429/502/503/504最多共用一次额外模型尝试；本地排版最多尝试32次、成品最多100页。自动修复不新增业务积分消费，但额外模型请求可能产生供应商费用；密钥错误、无效公式和不可信引用仍保留真实错误。过程页显示“自动修复与排版检查”，不把无法交付的任务标成成功。
- 模型格式兼容覆盖教案/备注的文本数组、单条要点、空的可选图形、图解文字节点与明确的数值字符串；无法无歧义转换的字段仍拒绝，并将具体页码、字段和预期类型反馈给修复模型及过程记录（不记录原始响应内容）。流程/时间线/路线/区间图超过4个节点时自动拆为首尾相连续页，区间图拆页前检查全局数值关系；各页按本段缩放，不跨页比较线段长度。
- 旧作品兼容流程：检索 → 教案及8–20页大纲（默认12页）→ 自动整理与真实PPTX预检 → 教师编辑/确认 → PPTX → 结算。新建课件改为上方三页先审流程。课件和动画工作台直接更新状态。取消、失败、等待超时释放预留。
- 七套视觉主题（新增明亮课堂）、七种页面版式：导入、概念、步骤、对比、例题、练习、总结；编辑文字、重点词、核心问题、教学表格、流程/时间顺序/路线/数值区间图、基础图表、讲解备注及答案。支持公式图片、基础示意图和教师上传有出处的配图；教案Markdown和PPTX下载。
- 我的作品支持新建、搜索、按类型/状态筛选、分页、打开编辑、重命名及删除。课件支持版本历史、旧版内容查看、旧版PPTX下载和免费恢复；恢复会生成新修订，旧版继续保留。活跃任务须先取消，关联的改写/动画未结束时禁止删除源课件；删除隐藏作品及其修订，保留历史账单和审计。
- 免费手工修改/换模板/重导出；单页AI修改独立预留5积分，文件保存与结算一致，失败保留原课件。
- 后台文档解析：PDF文字版、DOCX、PPTX、TXT、MD；状态、失败重试、删除切片；公开网页先预览再确认入库。
- 企业隔离检索、来源正文快照/页码/URL/hash/抓取时间；中文关键词、可选1536维向量、RRF融合、可选重排。
- 简单基础套餐500积分/模拟49元、加量100积分/模拟9元；重复支付只入账一次。管理员分配套餐留审计记录。演示生成价格：课件20积分、动画40积分、单页修改5积分。
- 个人成果对其他成员及管理员私有；管理员只能看到企业汇总和成员管理。
- 教学动画采用结构化分镜和受控图形组件，不再执行模型自由编写的动画脚本。Manim输出静音720p/30fps、20–45秒视频，支持多边形、圆、箭头、折线及刚性平移；可以复用本人已完成课件的来源快照。结构检查失败最多修复一次；成品进入教师验收，验收前只预留积分，取消/失败释放，验收后结算。
- 数据库持久化任务事件、SSE接口和页面过程树，基本仪表盘、模型调用记录、五条固定检索评测；可配置独立模型辅助评审。

样例模式 `APP_MODE=sample` **不调用真实模型、搜索或向量接口**。课件内容来自五个内置教学样例；PPTX、MP4、数据库和积分流程是真实执行。其它课题显示通用示例提示，不伪装成AI成果。样例动画是文字分镜淡入淡出，真实概念运动效果还需在线模型验证。

## 接入火山方舟

用户提供的 `https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks` 是内容生成任务接口。本项目课件文本客户端使用同平台的 `/chat/completions`，不能直接把前者填写为文本接口。

```dotenv
APP_MODE=live
LLM_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
LLM_API_KEY=在本地填写
LLM_MODEL=已开通的文本模型或推理接入点ID
```

文本模型需要能输出JSON；目前按兼容Chat Completions的 `model/messages/max_tokens` 协议调用。本地已完成方舟真实文本模型抽测。遇供应商错误会让任务失败并释放预留，不回退成样例冒充结果。

联网搜索实现Tavily兼容协议，本地已有联调记录；未配置时，明确关闭联网后仍可使用已入库资料。网页采集不需要搜索API key。搜索摘要标为“摘要”，不冒充已抓取正文。

Embedding独立配置地址、密钥、模型。当前pgvector索引固定1536维，首次选择模型需核对维度；旧的纯关键词文档不会自动补向量，需删除后重新上传。缓存按企业、供应商、模型、内容hash隔离。Rerank选配兼容 `/rerank` 请求/响应；辅助评审使用独立 `EVAL_LLM_BASE_URL/API_KEY/MODEL`，配置不完整时不调用，不借用生成密钥，评审失败不影响交付与结算。

密钥只放 `.env`（已被Git忽略）。前端不会获取或显示供应商密钥。

## 独立教学子Agent与模型配置

课件子Agent负责检索、教案和页面设计、PPTX制作及课件改写；动画子Agent负责检索、分镜、Manim代码及修复，或调用云视频工具。两者各有提示和模型入口，共享登录、教师确认、任务队列及账务。它们是应用内的专用工作流，未引入多进程或自由对话式Agent框架。

`COURSEWARE_LLM_BASE_URL/API_KEY/MODEL` 与 `ANIMATION_LLM_BASE_URL/API_KEY/MODEL` 分别选择模型，支持兼容Chat Completions的服务。留空的字段沿用 `LLM_*`；跨供应商切换时应把三项一起填写。辅助评审使用 DeepSeek 官方 API：`EVAL_LLM_BASE_URL=https://api.deepseek.com`、`EVAL_LLM_MODEL=deepseek-flash`，在本地 `.env` 填写 `EVAL_LLM_API_KEY` 后重启。旧 `LLM_EVAL_MODEL` 不再启用自动评审。课件评审在交付后执行，动画评审针对制作前的分镜方案；两者均是辅助意见，不能证明事实正确或替代教师审核。

联网检索优先使用搜索服务提取的正文，再回退到受限网页抓取；只有摘要时明确标记。网页和知识库内容按课题筛选段落、去除常见广告和完全重复段落，并保留相邻公式、适用条件与安全提示。来源面板展示保留数量和截断提示。当前采用关键词与上下文规则，并非 embedding 语义过滤；向量召回但未命中关键词的知识库候选保留并标记未做关键词筛选，选配 rerank 可进一步重排。评分和保留数量都不是事实可信度。

年级参与检索查询和两条Agent的提示，要求调整前置知识、推理步长、术语与练习难度。当前没有逐册教材章节索引及课程标准校验，不能保证自动排除所有超纲内容。

动画工作台可选精确教学动画（Manim，20–45秒）或情境视频（通义万相 / MiniMax / Ark，默认一段5秒静音短片）。前者用于公式、几何和受力解释；后者适合情境导入，不当作准确物理仿真。按2026-10-06最新需求视频使用 wan2.7-t2v，课件与动画分镜仍由各自文本模型生成。

动画质量链路：检索→结构化分镜→时长/边界/引用/声明的几何约束检查→可选DeepSeek文字评审→教师确认→受控Manim或云端情境素材→程序标注与媒体检查→关键帧抽查→教师完整播放验收→结算。云视频当前在独立底栏叠加首幕字幕/Unicode公式，不实现画面对象跟踪标注；提示不生成文字不能保证供应商绝不产生伪文字，仍须验收。

可选视觉审查独立配置 `VISION_LLM_BASE_URL/API_KEY/MODEL`（兼容Chat Completions且支持图片）。不借用生成或DeepSeek密钥；未配置/调用失败时明确要求人工检查。每幕留存3个关键帧，视觉模型最多看12帧，不能代替完整运动验收。发现问题时Manim最多进行一次分镜修复和本地重渲染，复查仍有问题则阻止结算；云视频不会为修复而自动再次调用收费生成接口。

旧的已交付视频不自动重做；旧未确认动画若没有 `scene` 字段会提示重新研究，不静默执行原自由脚本。待方案确认和待成品验收均保留24小时，超时释放预留。几何检查仅验证声明的关系，不是通用数学证明器，也不验证任意物理规律。当前固定深色高对比动画样式，主题设置不改变受控组件布局。

```dotenv
VIDEO_PROVIDER=dashscope
VIDEO_BASE_URL=https://maas.qianwenaiapi.com/api/v1
VIDEO_API_KEY=填写该视频平台的密钥
VIDEO_MODEL=wan2.7-t2v
VIDEO_DURATION=5
```

通义万相按用户提供的创建示例及[文生视频文档](https://help.aliyun.com/zh/model-studio/text-to-video-api-reference)适配：POST `/api/v1/services/aigc/video-generation/video-synthesis`，携带 `X-DashScope-Async: enable`；GET `/api/v1/tasks/{task_id}` 查询。支持 `wan2.7-t2v` 与 `wan2.7-t2v-2026-06-12`，2–15秒，720P、16:9，保留水印并开启提示词扩写。URL可以填写主机、`/api/v1` 或完整创建地址，不能填 `compatible-mode/v1`。图生视频及对话模型不适用于此通道。当前只取消本地任务，不声称远端已取消或免计费。视频有音轨时在隔离容器中复制画面流并移除音轨，再完整解码验收。

MiniMax仍兼容：设置 `VIDEO_PROVIDER=minimax`、`VIDEO_BASE_URL=https://api.minimax.cn` 及对应独立密钥。MiniMax 按[官方 V2 文档](https://platform.minimaxi.com/docs/api-reference/video-generation-v2-create)接入创建、查询与尽力取消，支持 `MiniMax-H3`（4–15秒）及 `MiniMax-H3-Max`（5–15秒），固定使用768P、16:9。H3原生生成音轨，服务端在隔离容器中无损复制画面并移除音轨后检查交付。运行中的供应商任务不可取消，业务取消不保证供应商免计费。MiniMax密钥独立，不回退到课件文本服务密钥；URL可填写主机地址或完整 `/v2/video_generation`，不要复制curl示例末尾的反斜杠。

原方舟配置仍兼容：`VIDEO_PROVIDER=ark`，`VIDEO_*` 优先于旧 `ARK_VIDEO_*`；仅方舟允许地址、密钥留空沿用 `LLM_*`。为保持旧作品兼容，内部 `animation_engine=ark` 仍表示云视频通道，具体供应商由 `VIDEO_PROVIDER` 选择。云视频配置在重启服务后生效。

适配器按官方Python SDK [volcengine-python-sdk 5.0.50](https://pypi.org/project/volcengine-python-sdk/5.0.50/) 的 `content_generation.Tasks` 协议实现POST创建、GET查询、DELETE尽力取消；兼容方舟 `/api/v3/contents/generations/tasks` 地址。即梦消费端会员、即梦其他开放平台凭证和方舟API并非可直接互换；未获得已开通的视频模型ID前不宣称即梦已联调。

教师确认后才提交视频请求；外部任务ID持久化，提交结果未知时不自动重复收费请求。下载走公开地址限制，在现有隔离镜像中实际解码全部视频帧，并检查静音H.264、时长和大小，保存本地后才结算。检查超时强制清理容器。取消和失败释放业务积分，但供应商可能已计费，接口不保证撤销或退款。单worker及超时失败的现有限制保留；不自动恢复跨进程中断的外部任务。

当前验证覆盖通义万相、MiniMax与Ark模拟供应商协议、模型路由、取消、失败释放、下载隔离、媒体元信息及损坏视频帧拒绝。使用模拟文本/视频接口与真实MP4，已跑通HTTP创建→教师确认→排队/制作→文件下载→仅结算一次→删除保留账单；并验证损坏文件及下载途中取消不会交付收费。2026-10-05已额外完成一次 **MiniMax-H3真实在线生成**：5秒请求，交付5.167秒、1344×768静音H.264，298908字节，浏览器播放通过，业务积分仅结算一次40分。详见 [MiniMax联调记录](docs/minimax-validation.md)。本机有 `edu-manim:local` 镜像时，可设置 `TEST_VIDEO_SANDBOX=1` 运行实际视频检查回归。

进度GET查询遇暂时断网或HTTP 429/502/503/504时最多尝试3次，按1秒、2秒间隔等待；认证、参数及响应格式错误不重试。创建视频的收费POST不自动重试，避免网络超时造成重复收费。

填写 `.env` 后可在项目目录运行 `./scripts/check-config.ps1` 检查缺项、误填接口路径和视频时长。该命令只读取配置，不打印密钥，不修改文件，不调用模型。检查通过仅说明格式及必填项符合要求，不代表密钥权限已验证。配置在重启服务后生效；真实视频还需单次在线联调。
