# PPT HTTP 422 修复 · 2026-10-06

## 原因与修复

- 两份勾股定理课件的模型生成已成功，失败在本地PPTX渲染。
- 一份使用MathText不支持的`\implies`；现在按完整命令名映射为等义`\Rightarrow`，同时支持`\iff`和`\impliedby`。未知语法仍报错，不静默删除公式。
- 另一份步骤页同时有图和公式，等高卡片留给正文的高度不足；改为按实际换行分配高度与紧凑内边距，不删文字、不缩小到16pt以下。
- PowerPoint检查发现另外两处轻微宽度越界，增加文本右侧安全内边距并同步换行估算。
- 本地渲染错误采用有限错误码、页码、字段返回；Go将其转换为中文HTTP 422提示。外部模型错误不当作本地排版错误解析，原始内容、密钥及堆栈不回显。

## 验证

- Python渲染回归75项通过，包括本次13个新增回归用例。
- Go全量测试和vet通过，验证首次生成失败释放额度、手工重导出失败保留原文件/版本/账单，以及错误信息的隐私边界。
- 两份原始12页课件在重启后的真实本地渲染HTTP接口重放，均返回200；页数、正文、讲解备注完整保留。
- 两份课件24页与六套模板42页的PowerPoint文字边界检查通过，无越界。
- 没有重新调用模型，没有修改用户原任务状态或积分流水。历史失败任务不会自动变成成功；修复产物单独保存于work/fixed-*.pptx。

本次修复排版与错误提示，不替代教师对数学证明、引用及教案的内容审核。证据：work/fixed-render-validation.json、work/fixed-render-preview/qa.json、work/theme-previews/qa.json。
