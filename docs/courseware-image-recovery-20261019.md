# 配图恢复修复（2026-10-19）

用户反馈：课件没有显示配图，失败草稿也不能处理配图。

## 已确认原因

自动网页检索找到相关但使用权限不明的图片后，仅返回待确认状态，丢弃候选素材；Commons 备用直连超时，不能补图。失败草稿原本又被编辑状态门禁拦截。界面使用 HTML 布局示意时，不能据此断言 PPT 内已经有图。目标旧任务还存在独立的时间轴内容检查失败，补图不代表该项已通过。

## 修复后的操作

1. 自动制作将待确认图片保留为本页私有候选，刷新后可查看，尚未授权的候选不进入 PPT。
2. 暂停且已有页面的课件可以进入“手动编辑内容”，确认使用权限后选择图片，或上传自己的图片，也可以跳过。修改后必须保存。
3. 保存重新渲染真实 PPTX 预览。暂停任务保持原状态、恢复检查点和已释放额度；教师通过原入口主动继续制作。暂停阶段不支持增删排序、审批、直接完整交付。
4. 图库暂不可达明确显示故障，保留候选、上传和跳过入口，不将故障描述为不存在图片。

## 验证边界与证据

先复现失败：自动制作丢候选、暂停草稿搜索返回409；增加真实模式验收后又复现暂停任务供应商调用门禁拦截。随后修复对应路径。

- 隔离 PostgreSQL + 真实渲染服务，HTTP 校验登录/成员隔离、版本冲突、候选留存、未确认图片拒绝插入、确认后保存、一页暂停 PPTX 下载、恢复检查点和积分不变。`work/image-flow-fix-20261019/live-green/http-results.json`。已检查实际 ZIP 内图片原始字节和教师权限声明。
- 浏览器使用真实 Vue 页面及明确标识的业务接口 fixture，覆盖网页与 Commons 图片选择、移除、停止等待、防迟到结果、上传替换、跳过；暂停一页草稿刷新留存、禁止审批。日志位于同目录 `browser-*-final.log`、`browser-final-paused.log`。
- 额外自动制作与预算/素材隔离回归记录在 `regression-final/`。
- 前端构建、格式检查、Go vet 记录在同目录日志。

这些确定性回归的搜索、网页与模型响应均为 fixture，实际 PPTX 由运行中的渲染服务生成；不冒充真实模型或史实质量验收。Commons 的外部网络连通性没有因代码修复而恢复。旧任务此前未保存的候选无法恢复，需用户重新检索或上传。

本轮不代替用户确认图片授权，不自动重跑其任务或审批，不新增业务积分，不推送 GitHub、不创建 Git tag。
