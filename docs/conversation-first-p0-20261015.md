# 对话优先首页与P0验证 · 2026-10-15

本次以用户最新要求调整：对话是课件制作的主要入口，教学资料与设置为选填辅助。P0工程进展与课堂质量分开记录，不将文件生成成功写成内容正确。

## 当前可操作流程

1. 首页输入一句课题描述，例如“九年级二次函数，40分钟，学生已学一次函数”。无需先填教学参数表。
2. 点击“发送”继续讨论。真实模型逐段回复，并在对话内展示“这堂课的安排”“教学重点”两块表格；教师可以继续补充。
3. 也可直接点击“直接制作三页预览”。当前未发送的文字先进入需求整理，完成后才创建一次任务；不要求额外确认摘要。缺少课题时保留输入并提示补充。
4. 教学资料与设置、可编辑摘要默认收起，需要时再打开。手工摘要随制作请求保存。
5. 制作沿用20积分预留、真实三页预览、教师审核、继续制作、最终确认及一次结算。仅聊天不预留制作积分。

首页保留既有紫水晶风格：深紫侧栏、浅色背景、白色对话区。桌面、短桌面、手机首屏可找到输入框；最近作品和工具为辅助入口。

## 技术与保护

| 功能 | 实现 |
|---|---|
| 流式对话 | Vue 3 + 原生fetch/ReadableStream；Go现有HTTP接口返回SSE，GLM上游使用真实stream请求，不用逐字动画模拟 |
| 需求表格 | 后端校验课题、学科、年级、课时等允许字段后，产生结构化block事件；Vue按文本渲染表格，不执行模型HTML |
| 停止与中断 | AbortController向上游传播取消；回复未完成不应用设置、不启动制作，保留输入和手工摘要 |
| 身份与用量 | 复用当前认证、会话续期、成员权限、资料归属和限流；企业或登录变化后不应用旧流事件；模型调用仍记录实际用量 |
| 数值检查 | Go标准库math/big精确核对显式数值四则运算及数字平方/立方；变量、一般幂、复杂公式不冒充已被程序证明 |
| 修改后的审核 | 仅已验证的编辑流程允许对待审核或已完成作品重新调用检查；继续使用持久供应商调用预算，生成worker的取消及尝试围栏保留 |

DeepSeek内容模型审核保持关闭，检查记录为disabled。确定性检查、Qwen真实截图审核和教师确认保留。内容审核候选的其他扩展及PDF候选未混入正式发布；动画继续停用。
