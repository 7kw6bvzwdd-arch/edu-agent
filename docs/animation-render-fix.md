# 动画兼容性与防复发 · 2026-10-06

## 已确认的原因

此次查到的两项异常走 Manim，不是 MiniMax 云视频接口。

- 欧姆定律（b508cab980fca1fd90e38329e74759ac）：首次使用不支持的 Dot(opacity=...)；第一次修复后仍有端点列表中的标量 0；第二次修复后仍有 self.wait(0)。逐个报错耗尽两轮修复，最终交付明确标记的文字分镜降级动画。
- 勾股定理（fc0a150b9f0d6f684352e0c0fe1a6533）：原脚本将 Rectangle 写入 camera.background 像素缓冲，引发数组转换异常；还拼错 ORIGIN 为 ORIGINAL。历史任务后来自动修复成功，不能把首次运行约100秒直接当作唯一根因。
- 根本缺口是模型代码与固定 Manim 0.19.0 接口不一致，且没有集中兼容检查；修复提示也未完整继承生成时的运行约束。

## 已实施

1. 生成和修复共享 Manim 版本、中文字体、20–45秒、480p静音、坐标及图形参数约束；修复携带确认分镜，要求一次处理全部已报告问题。
2. 渲染前在原隔离容器中用 Python AST 做语法和已知兼容检查，一次报告行号及多项问题。不会执行输入、自动改写教学内容或用正则改动字幕。它不是完整 Python 类型检查器，也不是安全沙箱。
3. 区分兼容预检、脚本执行、超时、媒体检查和环境异常；过程记录展示具体类别，预检展示修复建议。环境故障不触发付费模型修复；无有效变化的修复不再重复渲染同一代码，进入原有显式降级流程。
4. 任务有效性检查前移至首次代码模型调用前，已终止或结算任务不会再次调用代码模型。失败后的释放与成功后的结算仍由既有幂等事务负责。
5. 成品在独立检查容器完整解码，并检查 H.264、静音、480p及有限时长；检查有超时和容器清理。脚本沙箱仍非root、禁网、只读根目录、无密钥、有限CPU/内存/进程与输出。
6. 回归纳入 CI：解析规则测试及真实 Docker Manim 生成测试。没有增加依赖或重建智能体框架。
