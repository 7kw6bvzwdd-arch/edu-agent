# 对话课件工作台

2026-10-08。按用户截图与MagicSchool Raina交互方向实现，不复制品牌、图片或付费模板。给定网站链接跳转登录，未读取私有会话；交互依据为用户提供截图。

## 使用

1. 新建课件，填写原有课题、年级、目标、资料和模板设置，提交后工作台自动进入协作界面。
2. 首次只生成前三页：右侧选择页，手工编辑或在左侧选择“修改本页”提出具体要求；“讨论课件”只回答、不改内容。修改保存后实际预览更新。
3. 每页可点赞/点踩；点踩填原因后撤销该内容版本审核，不能直接带着点踩通过。针对原因修改后重新审核，或明确撤销反馈。教师确认前三页后才生成剩余页，前三页内容保持不变。
4. 全套逐页修改审核，明确费用和待核验内容后完整交付。原20积分预留只结算一次；草稿阶段不额外扣业务积分。已交付课件AI改单页预留5积分，成功结算；手工编辑/模板重导出和恢复免费。

底部审核栏提供“一键审核通过”，可由教师批量确认当前已生成的前三页或整套页面，保留原逐页审核/撤销。自动先保存修改并核对最新版本；存在任意未处理点踩时不提交任何页面审核。已通过页不重复提交；服务中断或版本冲突会显示真实状态，重试只处理尚未通过页。这是教师确认，不是AI自动审查，不会自动生成剩余页、交付或扣费。

课件区独立上下滚动，左侧对话与输入框不跟随课件长列表移出视野；鼠标滚轮、滚动条或聚焦课件区后的PageDown均可浏览。编辑、点踩原因及历史面板自动在课件区定位，手机布局也限制预览区高度。此次前端更新不需重新生成或迁移已有课件。

“惩罚机制”是作品内的负反馈约束与审核门禁，不是在线RLHF、微调或跨企业偏好学习；不会扣教师积分。模型仍可能输出不准确内容，需人工核验。全部供应商请求记录用量，即便没有业务积分扣款仍可能产生API费用。

## 工程边界

- 复用Go任务、成员私有/RLS、来源快照、账务、Vue组件与python-pptx，不引入新Agent框架或额外模型。
- 新请求含`preview_first:true`；旧请求与旧作品保持原流程。页ID持久稳定；审核绑定标题/主题/页面内容hash。不同内容的审核和点踩不被当作当前页结果，历史原因仍供修订参考。
- 对话历史私有持久化，请求幂等；输入1–600字，每作品最多60条。草稿同步修改有并发/过期/取消保护；成品修改复用原5积分异步修订，原件不被失败结果覆盖。
- 只生成剩余页，原三页保持不变。自动排版允许完整阶段无损续页，成品最多100页；预览恰好三页，不靠截断“过关”。单页AI修订若产生续页或影响其他页，保留原件并提示精简正文或移入备注。
- 本机原生PowerPoint输出PNG，单页预览鉴权并验证修订号。不具备Office的环境明确使用HTML布局示意，不冒充实际PPT截图，真实PPTX仍可下载。
- 保留教案/来源、模板、表格/图解/图表/公式/配图、备注、完整阶段增删复制/排序、MD/PPTX下载、历史内容查看/分页/免费恢复、课件转动画、继续制作。历史预览不足8页不会恢复成“完整成品”。草稿修改不证明内容科学准确。
