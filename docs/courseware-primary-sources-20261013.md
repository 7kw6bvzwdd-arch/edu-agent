# 四组课件验收的一手来源核对（2026-10-13）

本轮实际读取了人教社电子教材书目及部分目录图片，也读取了 OpenStax 的四篇教材正文。可用于生成的事实材料是四条 OpenStax 第一方短原文；人教社目录仅用于核对册次、章节和版本，不作为教学正文入库。本轮没有获得完整的人教版章节原文，不能把本轮生成结果表述为“已严格复现人教教材内容”。

## 2. 提供给生成端的资料

生成端文件：`work/courseware-full-quality/verified-sources.json`。其中只有四条实际读取的短原文，每条带课题、标题、精确 URL、正文小节位置和 `primary_source_original_excerpt_not_pep_textbook` 标识。内容是英文原文，不把中文译文或自编摘要冒充原文。

人教版目录证据：`work/courseware-full-quality/pep-catalog-evidence.json`。它单独保存，不进入教学正文检索。

独立验算和使用边界：`work/courseware-full-quality/primary-sources.json`。独立例题标记 `calculated_fact`/`constructed`；从未称作教材原例题。相同文件也保存在工作区 `work/courseware-acceptance/primary-sources.json`。

核心边界：

- 一次函数：OpenStax 的 linear function 分类也讨论零斜率常函数；验收中的一次函数采用 `y=kx+b，k≠0`，不能把常函数混入一次函数。
- 浮力：使用 `F浮=ρ液gV排` 时必须标明液体密度、单位、重力加速度取值，`V排` 是排开液体的体积。用测力计作 `F浮=G-F示` 时明确物体静止、只受重力/浮力/测力计拉力，不接触容器底部。密封贴底等特殊边界不套常规结论。
- 二次函数：`a≠0`；实际问题带定义域。图象顶点与受限区间最值需要区别，不把整条抛物线结论直接套给受限情境。
- 电路：理想直流电源、欧姆电阻，忽略导线及电源内阻；不得把定值电阻关系无条件套在非欧姆器件。自编教学实验只用低压电池，改接先断开开关，电流表串联、电压表并联。这些是验收设计约束，未称为上述短引文中的安全规范。

独立样例包括一次函数 `y=2x-4` 与 `y=-x+4`、二次函数 `y=(x-1)²-4`、水中排开200 cm³的2 N浮力、6 V与10 Ω/20 Ω电阻的串并联。上述例题为本轮构造，不是假装查到的教材原题。

## 3. 实际访问限制

1. [教育部2022课程方案和标准通知入口](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)实际请求被转向 HTTP 并返回403“当前访问疑似攻击行为”。尝试带查询参数仍403。因此本轮不标记“2022数学/物理课标原文已核实”，也不臆造附件页码。
2. 人教社旧学科入口 `https://www.pep.com.cn/czslx/`、`https://www.pep.com.cn/czwl/`返回维护页，不能当作已读取的教学文章。
3. 新入口 [jc.pep.com.cn](https://jc.pep.com.cn/)返回200，可读取网页公开脚本中的书目及官网阅读链接。书目脚本是公共前端用于展示的数据，没有使用任何账户、私有接口或密钥。
4. `book.pep.com.cn`第一次直接请求返回403 `denied by Referer ACL`。带正常书目点击 Referer `https://jc.pep.com.cn/`后返回200，可读公开入口和一部分书页。后续部分页图返回 HTTP200 **但正文为 Page Verification HTML**，并非图片；检测了内容类型并停止，没有绕过验证码或将这些响应登记为教材正文。
5. 电子书 `search_config.js`对八下数学、八下物理为空文本；九上数学、九年级物理只有乱码重复水印，无可用正文。`files/basic-html/...`返回404内容，不能仅凭HTTP200判定正文可读。
6. 已读取的九上数学页面带“仅供个人学习使用，未经授权不得另做他用”水印。此次保存短目录转录和来源核对，不导入或分发整本教材；建设正式教材语料仍需要明确适用授权和版本。

## 4. 导入与冲突处理建议

最小可行导入记录应包含：出版主体、书籍资源 ID、学制、学科、年级、册次、实际核实版次（未知则保留未知）、章节、印刷页码与图片/PDF页序映射、源 URL、读取时间、内容哈希、内容类型、核验范围。原文、译文、摘要、自编例题应有不同来源类型。

检索遇到同主题不同章号、不同版次或不同学制时，不把文章合并成一份“人教版标准答案”；先按教师选定教材文件/书籍 ID锁定版本。教材目录只证明位置和教学编排，不证明例题或公式正文。教学正文不可读时用通用事实来源核对、保持明确来源标签，不补写“教材第几页原文”。

来源可靠不代表可直接授课：OpenStax 电路是大学教材，生成端仍须限制初中九年级内容，不引入本轮未要求的基尔霍夫推导或复杂网络。文字审核核对物理/数学条件与推导，画面审核核对实际图象和电路；独立数字验算作为回归事实，不能替代显示检查。
