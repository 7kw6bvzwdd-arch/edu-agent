# 课件制作自动恢复（2026-10-12）

此前单页修复三轮后、渲染或审核暂不可用、阶段等待超时时，worker 统一结束任务并释放预留，导致教师反复点击“继续制作”。现将可恢复错误接回原队列，保持同一作品、检查点、教师审核与原积分预留。

- 单轮仍限制局部修复次数；用完后持久化下一轮时间，15 秒开始指数退避，最长间隔一小时。生成了新的页面后重置连续故障计数。持续故障时可取消并释放预留。
- 已保存页遇到审核中断时重新审核，不为审核服务中断重新生成。已完成、已审核页内容保持不变。内容与实际截图审核均必须通过，不能以自动恢复为由跳过质量检查。
- 自动恢复不调用手动续作接口，不添加作品，不新增额度预留或计费周期。队列等待不会占住生成 worker；后台重启后的过期执行 lease 会接回队列。
- claim attempt 在同一计费周期内隔离迟到 worker，限制其检查点、状态提交与计费收尾。已取消、已删除、权限撤销、模型鉴权失败和缺失审核配置不会自动复活或盲目重试。
- 页面显示“正在自动恢复制作”和“无需操作”；保留三页预览教师审核及最终交付审核。

隔离数据库测试覆盖输出截断、排版服务中断、审核响应异常、lease 到期、持久化退避、同 ID、一次预留、旧 worker、取消保护和真实 PPTX；浏览器回归拦截全部业务 API，验证自动恢复提示、无手动续作按钮及预览图稳定。接口测试采用受控模型响应，不代表真实教学内容质量已全面验证。

历史已失败并释放预留的作品保留原状态；恢复历史作品仍通过已有手动入口，不自动重新占用教师积分。新制作或恢复后的制作过程采用自动恢复。

验收结果：新增自动恢复/审核中断 HTTP 回归通过（包括 null 页面草稿），截断与渲染中断续作、同作品/计费周期保护回归通过；不连接数据库的默认 Go 测试、vet、后端构建、前端构建和浏览器回归通过。完整数据库集成套件在十五分钟上限中止，未完成全部集成测试，不记为全量通过。两座临时测试数据库已清理。

部署：确认生产活动任务为零后重启 8080 后端。健康接口返回 `courseware_auto_resume_version=auto-resume-v1`，独立内容及视觉审核均已配置；后端二进制和前端入口与当前构建一致。
