## 用户问题与修复

此前普通讲解以单个外框承载标题及全部items，动作只能作用于整组。现在每条内容独立渲染，新增item_sentences与本幕旁白一一绑定，程序依据真实语音句子时间控制350ms淡入、当前项强调，已讲要点保留。完整旁白仍在字幕区域。旧作者数据未绑定时不猜测时间。

知识卡呈现分散要点；对照采用并列项（窄列下纵排）；时间线/关系链采用独立编号节点与连接（宽屏横排、窄列纵排）；插图在图旁逐项标注。没有开放自由HTML或引入新依赖。核心结构和运动仍由既有scientific渲染，文字效果不算真实学科动画。

生成提示词、严格结构校验、CLI模型生成、HTTP生成/方案编辑/AI局部修改均接入绑定要求。新生成或改动组件漏绑时使用原有有限修复次数；历史原样对象和旁白兼容。渲染版本改为lesson-text-v4，参与原有hash及审核失效规则。HTML与MP4同源。
