# 教材原文与课件结论关联 · 2026-10-13

本轮完成可操作的候选切片：选教材时保存实际文档文字快照、教师版本标注、章节和文件页序；生成页保存具体结论与连续原文摘录；教师可以在每页展开查看摘录与上下文，PPTX讲解备注保留关联及出处。没有增加数据库表、模型服务或业务积分收费。

## 已实现

- 教材快照由服务端读取，客户端提交的原文、版本快照或出处不能冒充保存资料。版本标签来自教师，不是出版社版次认证；未标注时明确显示未知。文档指纹为完整抽取页文字的SHA-256，不是PDF文件字节指纹。
- 生成模型指定正文位置，如bullets第0项，后端读取真实原句保存为claim。保存后去掉动态位置：教师改写原句会使旧关联无效，不能把旧摘录静默搬到新结论。兼容已有作品的无结构关联引用，但不补标为已认证。
- 服务端检查来源ID、来源快照hash、连续摘录是否确实存在、结论是否存在于本页。目录、搜索摘要及明显异常文字层不能作为教学结论依据；选定教材的关键词/向量召回切片也不能绕过这项检查。新检索快照带来源正文性质，引用编号需相应证据关联。
- 文字审核负责摘录是否真正支持结论、适用条件与版次边界；字段和hash校验只证明可追溯，不认证事实。画面审核和独立解题不接收隐藏的证据结论或摘录，避免泄漏教师答案。
- 新工作台及旧工作台来源页可查看每页结论、摘录、版次、文件页序与上下文。编辑时可移除旧关联并标待核验。教材预览显示目录/文字提取异常提示，不把文件页序冒充印刷页码。
- 三页预览、剩余制作、单页修改、免费编辑、交付与续作复用保存快照。错误关联走既有有界同页结构修复，不另生成作品或新增业务积分；持续失败仍保留草稿，不伪装成功。

## 验证与实际失败

先复现了伪造摘录、不存在来源、旧hash、课件中不存在结论、目录充当正文及缺关联被旧代码接受。实现后这些失败用例通过。字段位置、缺少索引及越界、后续编辑旧关联失效、导出不改写保存备注、隐藏答案隔离亦有回归。

默认Go最后87项顶层通过、112项条件测试跳过；go vet和候选构建通过。独立HTTP第一轮4项通过：新关联完整流程、教材/参考隔离、三页门禁、既有交付流程。最终变更后新关联流程与教材隔离两项再次通过，约192秒。这里的默认测试不等于全量数据库HTTP测试。

HTTP使用隔离数据库与样例内容、真实PPTX渲染，验证客户端快照/出处防伪、跨企业/成员作品隔离、错误保存不改变作品或积分、教材后来改标版本不改变已保存课件、预览审核后扩展、最终导出备注中的出处与hash。隔离库均已清理。

浏览器使用拦截的样例API：每页摘录和教师版次展示、文件页序区别、教材预览版次/目录提示、隐藏答案与课堂演示、390px无横向溢出通过。构建输出到独立候选目录，没有替换正式前端。

真实模型试验保留三轮，不拼成稳定成功率：

1. 首轮GLM重复改写claim，连续两次有界输出后关联失败。保留失败日志，未保留供应商用量汇总；因此不编造本轮所有调用的总tokens。
2. 字段位置关联后，真实生成与正确/错误结论文字审核通过；直接请求生成的一页因文字过密未通过渲染。保留实际输出及失败，没有人工删改后冒充自动通过。该轮1次GLM生成、2次DeepSeek审核，供应商报告10700 tokens。
3. 最终使用项目现有单页生成/渲染路径和教学任务约束，取得实际一页PPTX；正确结论放行，故障注入的“正斜率递减”被按知识、答案及来源不支持拦截。该轮1次GLM生成、2次DeepSeek审核，供应商报告10592 tokens，约34秒。没有视觉模型调用；之后实际Office导出单页PNG并人工查看，无明显遮挡或裁切。只证明该样本能显示，不等于画面模型或整课教师验收。

真实依据是此前实际读取的OpenStax英语段落，明确标补充事实参照，不是人教教材。坏结论是故障注入样例，不是GLM实际生成坏页。所有模型调用发生在隔离任务，涉及实际供应商费用，没有真实教师作品或业务积分写入。

## 已发现但尚未解决

实际只读抽查用户上传的《【人教版】九年级下册数学电子课本.pdf》文件第11页，发现/G字形、狓/狔等字体映射、分式位置丢失；该页实际是26.1.2反比例函数图象与性质，提及二次函数不能把它当作二次函数章节。教材标签尚未填写，不能猜出版年份或把官方新版目录贴到这本书上。

本轮检测并阻止明显损坏文字作为结论证据，没有修复PDF文字层、重解析原文档或新增OCR。此检测只覆盖明确的缺字/异常字体信号，不能发现所有分母、指数、图示信息缺失。需要下一步对教材实际画面与公式提取做校准，再扩大可用原文范围。

官方完整可读人教正文、出版社准确版次索引、任意自然语言结论语义认证、全课图表质量与模板感仍未完成。真实小样本不是四课题全量生成质量或课堂验收。
