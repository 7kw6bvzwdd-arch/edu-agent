# 课堂图解与课件质量验收 · 2026-10-07

## 目标与实现

用户希望课件接近教习网公开预览的教学质量。参考课堂信息层级、材料与问题的配合，未复制原站课件或受限素材。

- 新增白底、绿色标题、黄色核心问题区的“明亮课堂”，共七套主题、七种教学版式。
- 生成契约要求具体例题、独立练习、教师备注与教学图表；检测重复标题/正文、备注不足、缺少图解及渲染溢出，最多修复一次。结构合格不代表事实正确。
- 教学表格、流程图、时间顺序图、路线示意、数值区间图、重点词和核心提问可在网页编辑，导出为可编辑PPT文字、表格与图形。顺序图明确不按时间比例；区间图必须提供单位、递增有限数值和对应节点。长度按数值绘制，引导线分离相近节点标签。
- 数字与常用单位保持同行，重点标注仍有效；表格加图片时优先保证表格宽度，图片保持比例。过密内容给出页码和字段，不截断隐藏问题。
- 教师可上传PNG/JPEG，填写说明与出处；禁止模型伪造图片网址。图片来源写入备注，单页AI改写保留原图，文字模型不接收二进制图片。
- 前端检查后端media-v1能力，后端导出检查排版服务能力，阻止旧服务静默忽略新字段。这是兼容性保护，不表示服务已部署。
