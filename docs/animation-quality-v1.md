# 动画质量链路 · 2026-10-06

本轮覆盖全部新建动画，勾股定理只作为回归课题之一。历史已交付文件不重做、不补扣积分。

## 行为变化

1. 研究模型输出每幕目标、时长、字幕、Unicode公式、证据类型、来源ID、图形、刚性平移动作和几何约束。JSON对象输出约束与本地字段校验同时执行；格式或规则失败最多修复一次。规则检查汇总各幕首个问题及总时长问题，一并交给修复模型，避免前幕错误掩盖后幕；修复结果仍须完整校验。证据类型逐幕选择，代数推导和讲解不能沿用拼图幕的proof标签，也不能靠改标签或删除失败约束冒充证明通过。
2. 直角三角形和矩形由锚点、边长、朝向构造；其他凸多边形、线、箭头、圆和折线可组合。检查坐标、移动后的边界、文字长度、时长和引用；声明的直角/等长/等面积/拼图覆盖关系必须成立。重复顶点、重叠、越界和面积不守恒的拼图不能以证明身份通过。
3. Manim解释受控JSON数据，不再执行模型自由脚本；统一深色背景、文字区、图例区和演示区，全片图形使用同一缩放比例适配，保留跨幕长度和大小的相对变化，视频为1280×720、30fps、静音。没有自动文字动画降级收费。
4. 云视频生成请求只要求情境素材；首幕字幕/公式由程序置于独立底栏。禁止文字的提示不保证上游完全遵从，验收仍检查伪文字；不做对象跟踪标注或云视频自动付费重生成。
5. 独立容器检查完整解码、格式、时长，Manim每幕抽取3帧，云视频抽取5帧。关键帧按成员私有保存，通过鉴权接口查看，取消/删除后不可访问。
   Manim每幕按10%/50%/90%抽帧，分别覆盖图形渐次构建、讲解/动作和结果；图例随图形出现，字幕与公式在对应阶段出现。
6. 可选视觉模型独立配置 `VISION_LLM_BASE_URL/API_KEY/MODEL`；只看最多12帧，明确为抽样检查。没有配置或接口失败时不能冒充视觉通过，交给教师完整播放。发现问题则Manim最多修复分镜并本地重渲染一次；已知问题未验证消除时阻止结算。
7. 两条路线都进入 `awaiting_acceptance`，仅预留积分。教师明确验收后结算；取消、技术失败或等待24小时超时释放预留。验收与取消竞争不会误报结算成功，重复验收不重复收费。

DeepSeek仍负责教学方案文字评审，不负责图像检查；教师修改确认后旧文字评审失效。公式出处检查目前是引用ID合法性，不是逐公式事实证明。

## 已知限制

- 可执行动作目前是刚性平移和场景转场，尚不支持旋转动画、复杂物理仿真、任意曲面或语音。
- 几何约束只核查模型声明的关系；不能自动理解任意证明文本，也不会把一次正确数值拼图等同一般性证明。抽帧可能漏掉中间时刻的问题，教师需播放全片。
- 模型仍可能给出缺少上下文或教学含义不足的分镜。规则不合格时阻断交付；规则通过也只是待验收预览。
- 旧未确认动画缺少scene字段时明确提示重新研究。旧成品仍可下载。
- 本地视觉密钥未配置，真实视觉模型未联调。自动审批策略拒绝启动隔离浏览器测试服务，页面完成生产构建，真实浏览器验收仍待执行。
