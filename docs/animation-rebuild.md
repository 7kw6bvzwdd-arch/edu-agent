## 新引擎设计 · 2026-10-15（已确认，待实施）

需求结论见SPEC.md文首“教学动画新引擎决定”。本节记录实现约定；当前代码仍是停用状态，以下内容均未实现。

### 生成边界
- 模型输出结构化场景描述：逐幕目标、显示文本、朗读文本、对象（受控组件类型与参数）、动作组合、教学停顿、来源ID。程序校验后由播放器绘制，不执行模型代码，不接受模型提供的HTML/CSS/JS、外链或坐标脚本。
- 字幕不由模型输出：程序按句从旁白显示文本生成，方案页展示的字幕即该派生结果；作者数据中出现独立字幕字段即拒绝，避免字幕与旁白不一致。
- “构图”指模型从组件声明的版式槽位中选择（如主区/侧栏、左右/上下分区）与组件间的相对关系；绝对像素坐标由渲染器按槽位与学科计算得出，模型给出的坐标一律拒绝。数学对象的参数（如k、b、取值区间）属于学科参数，不是画面坐标。
- 受控组件首批服务首个课题：坐标系、函数图像（按解析式计算，参数可随时间插值）、点/线/标注、文字与公式、强调框、对比面板。其后按课题增加几何与受力组件。准确性来自程序计算，模型只给参数。
- 动作由有限原语组合：出现/消失、参数插值（如k从1到3）、移动、强调、等待教师点击、固定停顿；同一组件可在多幕复用，构图位置与组合由模型选择，避免所有作品同一版式。
- 校验：参数范围、对象引用、时间轴重叠、文字长度与实际排版溢出、公式可渲染、朗读文本存在且不含未转换符号、旁白描述与图元参数一致。斜率类旁白不能只比对“k是否增大”：k的符号决定增减方向，|k|决定倾斜程度，二者分别校验。比较直线陡缓**只看|k|，不要求k同号**——同一坐标比例下k=−3比k=1更陡；“变陡”要求|k|确实增大，k从−3增到−1是k增大但|k|减小、直线变平。**连续参数动画**另按一条规则处理：k连续变化经过k=0时已不是一次函数（k≠0），须明确说明退化或把区间拆开分段演示。首个验收样例可限定在k同号区间内演示作为教学简化，这是样例取值约定，不是通用数学规则。不合格时同幕有界修复，仍失败则如实失败。

### 语音与字幕
- 火山引擎豆包语音，单向流式HTTP优先；配置独立TTS地址、密钥、资源/音色ID，不写入代码和日志。首版固定一个普通话女声，试听锁定后记录音色与参数。
- 合成策略**只选一种**：探针与试听后在「按幕/按段合成」与「逐句合成」之间选定其一并写死为配置；时间轴以实际音频时长为准，动画节点对齐旁白句。字幕取自旁白原文，按句显示（不逐字高亮）。选定后**不保留另一档作为运行时降级**——运行中失败走有界重试，重试耗尽即明确失败，不得悄悄切换策略（两档的缓存键与失效单位不同，混用会让修改范围与计费不可预测）。切换策略属于重新验证后改配置。
- 公式与符号在方案阶段生成明确朗读文本，教师可在方案中查看和修改。教学停顿由播放器插入，不依赖SSML。
- 待真实账号验证：流式接口的时间戳返回形式、中文数学朗读效果、并发与计费方式。验证前不把SSML或时间戳作为必需依赖。

### 制作阶段与状态
复用现有任务、对话、预留/结算、取消、事件和私有文件机制：
1. 需求对话与摘要（不预留）。
2. 分镜方案与静态示意帧；对话修改只重做改动幕并保存修订（不另扣业务积分，模型调用仍有供应商成本）。
3. 确认方案时预留40积分，模型选择代表教学幕（须含实际图形变化），生成该幕的真实画面、语音与字幕预览。
4. 教师确认代表幕后锁定该幕内容hash，生成其余各幕；代表幕不重新生成。
5. 完整HTML包验收后一次结算；取消、24小时等待超时或最终失败释放。系统修复不计教师修改次数。
6. 交付后每幕一次免费局部AI修改（只重做该幕画面与语音并保存新修订）；更换知识点、增加目标或整体重做提示为新请求。

### 交付物
- 单个离线HTML包：内置播放器、场景数据、字体/公式渲染资源和音频，不依赖外网；提供暂停、进度跳转、回放、逐幕/分步播放和字幕开关；在平台内同样可直接播放。下载与在线播放沿用成员私有鉴权。
- 导出的场景数据只含已校验组件参数，播放器不解释任意代码；CSP禁止网络请求。
- 第二阶段MP4：无头浏览器确定性逐帧录制并合成音频/字幕，点击等待转为固定停顿；不阻塞首版上线。

### 首个端到端验收：一次函数中改变k
真实模型生成方案→对话修改一次→确认→代表幕（k变化引起直线倾斜变化，含语音字幕）→确认→其余幕→完整离线HTML在无网络环境播放、暂停、跳转、分步播放→验收结算40积分一次。同时验证取消释放、跨成员访问拦截、样例模式标注无真实语音；记录制作耗时（目标2–5分钟，不含排队）与成片时长（30秒–3分钟），二者分开报告。

### 实施进度 · 2026-10-15（内部技术验证，未接入任务/HTTP，旧引擎仍停用）
已完成（backend-go/anim*.go，均有测试）：
- 作者数据schema与校验（animscene.go）：严格解码拒绝字幕/时间轴/坐标等字段；组件仅axes/line/point/equation/text/panel，槽位main/side；斜率旁白按符号与|k|分别校验、静态陡缓比较只看|k|、连续经过k=0须说明；旁白中的“k从A到B”、y=kx+b、点标注须与参数一致；朗读文本禁止数学符号；代表幕须含直线参数变化。
- 时间轴（animtimeline.go）：实际音频时长⊕停顿，动作绑定句子/前一动作/幕首尾，同对象同参数插值重叠即拒绝；成片超出30秒–3分钟给警告。
- 火山V3 HTTP Chunked客户端（animtts.go）：X-Api-Key/X-Api-Resource-Id，逐行解析base64分片至code 20000000，解码MP3/WAV实际时长；同单元有界重试，业务错误不重试，错误不含密钥；只实现逐句合成，ANIMATION_TTS_UNIT非sentence视为未配置。
- 单文件离线HTML（animpackage.go + animplayer/）：CSP default-src 'none'，内联脚本/样式按sha256放行，音频data URI；render(t)纯函数，音频驱动句内时间，自动/分步两种模式，暂停、跳转、回放、上一/下一幕、字幕开关；样例脚本、无语音、测试音分别明示。
- 开发命令：`edu-server --anim-package <script.json> <out.html> [estimated|tone|tts]`、`edu-server --tts-probe [dir] [text]`（需先加载.env）。
- 验证：go vet、go test全部通过；scripts/browser-animation-package.cjs在Edge无头、断网下对测试音包16项、无语音包14项检查通过（CSP无违规、无网络请求、1440×900各幕文字不溢出、1920×1080字幕在框内、跳转状态一致、分步等待/继续、自动不等待、暂停冻结、音频驱动时间误差<120ms）。

未完成：真实TTS探针与试听（缺API Key与音色）；真实语音下字幕偏差实测；字体与公式资源内嵌（当前用系统中文字体）；模型生成方案、对话修改、代表幕确认、预留/结算、任务与HTTP接入、前端入口；AIGC标识合规核验。
