# 课件文字与画面审核分工（2026-10-13）

用户决定保留两种独立审核，重新分工。复用原有逐页流程、独立审核模型、局部自动修复和真实Office截图，不增加模型、依赖或教师确认步骤。

## 职责与输入

| 环节 | 负责内容 | 输入 |
|---|---|---|
| 文字与教学审核 | 知识、适用条件、安全、推导计算、答案单位、教学目标、图表实际意义、来源支持及内容一致性 | 当前页正文、公式、图表参数、完整备注/答案、实际资料快照与当前页规划 |
| 画面审核 | 裁切遮挡、投屏可读性、应有内容却为空的填色面板、实际显示与输入不一致 | 真实Office截图、函数图同图放大裁剪、预计显示的页面内容与程序计算事实 |

图表是否有教学意义由文字审核负责；应有图表/公式却没显示、错标签、明显错绘由画面审核负责。画面模型不重新解题、不审查隐藏答案与备注。视觉输入删除全课教案、旧评审、检查点及规划，仍保留实际可见公式、图表/表格及配图说明；原始草稿和备注不修改。

## 程序边界

- 文字问题类别：`knowledge / conditions / answer / pedagogy / source / consistency`。
- 画面问题类别：`layout / readability / empty_panel / render_mismatch`。
- 两种结果均要求确定性 `confirmed / uncertain`，服务端记录审核来源。
- 画面阻塞错误必须有位置、实际显示、预期显示及具体问题证据；这些证据一起传入当前页修复，不因显示问题要求全套重写。
- `render_mismatch`还需提交本页输入字段的JSON Pointer及从截图读到的JSON值。程序从原始输入读取预期值，不接受模型另外提出的新数学答案；读值与输入一致时按建议保留，不能因此重做。引用不存在的字段、隐藏备注或其他页面则视为审核未完成。此机制仍依赖模型准确读取截图，不是像素识别的确定性证明。
- 公式对照允许空格和TeX字体/间距标记的差异，保留数值、符号、指数及分组含义。字体代码没有显示在截图上不等于内容丢失，真正错数值和公式继续阻塞。
- 审核结构不合规范时，用同一张截图自动重查一次，不启动Office、不调用生成模型；每次供应商调用仍单独记录用量，不增加成员业务积分。仍无效则沿用已有草稿恢复，不通过放松审核冒充成功。
- 明确错误继续阻塞。模型声明不确定的读图估测及审美建议记为suggestion，不能触发重做。分类越界、证据不全、截断或缺失结果视为审核未完成，按既有审核故障恢复机制保留草稿后重新检查，不能冒充通过。
- 数学公式与关键点仍由既有程序计算提供事实，不能以小刻度肉眼估测推翻；实际明确错绘不能因计算正确而豁免。
- 已完成页面和已有审核不因规则升级全量重做。后续新生成/变更页面采用新分工；三页教师预览关卡、局部自动修复、任务取消和成员独立计费保持原行为。
