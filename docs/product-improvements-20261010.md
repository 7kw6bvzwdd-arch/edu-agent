# 2026-10-10 已确认改进的实施记录

用户“目前的内容可以开始做了”授权本轮实施。以下区分流程实现、文件验证与真实模型质量，不把所有讨论项视为已经验收。

## 本轮已实现

- 新建数学/物理课件以内容详略（精简、默认、详细）、课时、学生基础和参考用途代替固定页数。默认约十五页仅作规划参考。整课规划保存逐页目标、教学任务、视觉用途、符号约定、时间与关联页；必讲时间超过课时的规划退回修正。最多一百页是文件处理保护，触发保护不会冒充完整交付。
- 按规划生成三页代表性质量预览，教师逐页审核并确认后制作其余页，最终回到教学顺序。原页 ID、正文和审核保持稳定。
- 新流程逐页做独立教学内容审核和实际 PowerPoint 截图审核，输出对象、证据、严重程度及修复目标。明确错误驱动有界单页自动修复，轻微美观建议不阻塞；审核缺失或异常属于不可用，保存草稿并停止。恢复后先审核已保存页面，不因审核服务故障重做内容。
- 提交新质量流程前检查审核配置；缺失时保留需求、不创建作品、不预留积分。真实模式不允许样例检查代替模型审核。
- 手改保留服务端规划和审核字段，清除受影响的旧检查；规划关联页的教师确认失效，需核对后重新审核。轮询保留未保存编辑，旧修订不覆盖新修订。旧生成计费周期不能写入新续作检查点或释放新预留。
- 续作复用同一个作品与历史账务；多次点击只预留一次，不再产生新的失败作品。还原只移回当前作品，随后手动继续。
- 待处理与已取消最多十二条。自动清理超额的最旧无内容记录，保护有页面或文件的草稿；无法清理的超额草稿保留在当前作品并显示容量提示。勾选及全选删除当前筛选页，批量校验原子执行，成员与企业隔离。
- 用量记录每页五十条，起止时间查询，勾选/全选本页；另可明确选择指定时间范围全部记录，删除前显示数量和范围。删除明细保留累计用量、统计与积分账单。
- 明细每成员最多五千条及九十天；日汇总九十、月汇总二十四、累计一条，按自然日/月滚动清理。P95仅说明当前保留明细范围，不能恢复已删除明细的精确全期P95。
- 版本采用最近二十个及首个版本的保守保留规则，当前成果和其他作品仍引用的文件受到保护；后台清理独占历史文件、预览及孤立临时产物。活跃任务、对话与最近一小时新文件延后清理。账务记录独立保留。
- 检索拆成最多三条查询，保留学科/年级/教材约束；拒绝将搜索摘要作为教学证据，过滤过短正文、下载/登录/购买页，URL和正文去重，最多十二条来源快照。机构来源优先候选但仍注明待核验，独立内容审核检查结论、公式条件及来源支持。
- 去掉图表、版式及长课件例题数量配额，要求表达服务于教学目的。比较页用开放文字与分组线，练习重点面板随文字高度调整。新规划课件公式导出为可编辑 Office 数学对象；旧课件保持原来的栅格公式导出。
- 当前教师同学科、年级、课题的最近反馈进入生成提示；不跨成员复用偏好，不声称自动训练。
- 交付后的课件状态只汇总已保存页面的内容/截图检查；结算入口再次校验规划、页面数量、内容哈希和检查状态，未完成检查的课件不会结算。

## 本轮验证

- Go单元检查及 go vet 通过；独立数据库 HTTP 验证作品身份、重复预留、失败恢复、代表页顺序/审核保留、容量保护、批量原子性与隔离、删除与共享资源、日志分页/时间查询/累计保留、五千条/九十天明细上限及版本容量。
- 审核不可用故障测试证明：保存已生成页面，重新继续时不再调用生成模型；严格审核返回结构及错误/建议分级。
- 使用真实 PowerPoint 生成截图，通过模拟审核接口确认传入 PNG，明确错误阻塞而建议放行。这验证链路，不证明真实视觉模型识别率。
- Python 153项渲染测试通过，产物为真实PPTX。Office打开并截图两页验收样例，中文公式上下标、分数正常显示；公式结构具有原生数学对象。跨Office版本兼容性尚未验收。
- 浏览器验证桌面/390px窄屏，作品还原删除、调用记录分页与跨页范围删除、确认框焦点、累计保留；预览图片稳定、进度、未保存编辑保护与图像局部更新。
- 当前真实独立文字审核模型对三个明确样例抽测：两个已知知识错误被拦截，正确计算放行。仅为狭窄内容抽测；不代表完整课件已达到精品教学质量。
