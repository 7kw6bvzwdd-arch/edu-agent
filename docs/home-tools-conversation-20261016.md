首页沿用紫水晶导航、浅色图案背景与现有侧栏。首次发送需求后，居中输入区通过原生 View Transitions 过渡到铺满主内容区的对话，保留导航；开启减少动态效果时直接切换。底部输入区保持可见，准备快捷项与最近作品在对话展开后收起。

## 交互

2026-10-16补充：展开后的对话输入区改为36px默认输入高度，工具切换、按钮和间距同步压缩；不会放大初始首页以外的输入区。课件制作统一保留一个画布入口，编辑画布直接替换静态PPT预览，按钮可返回预览。教学内容与讲解设置收纳到同一编辑区的折叠项；无画布支持时保留内容编辑兜底。前端构建、首页8组与完整画布10组浏览器检查通过，含新增紧凑高度与单画布断言；本地前端已更新，后端未重启。

- 首页提供自动选择、课件制作、教学动画。统一需求接口根据对话返回经过校验的工具和讨论/制作决定；明确制作需求可以直接启动对应工具。工具范围为系统当前已有的两项制作工具，不增加通用代理或外部工具执行。
- 课件与动画分别复用已有工作台，以独立任务嵌入同一会话。课件真实鉴权预览、逐页审核、继续制作及下载仍走原接口；动画保留方案确认、代表幕审核、成品验收、局部修改和HTML下载。
- 动画仍是已实现的一次函数教学切片，不承诺任意学科动画。对话不绕过权限、可用额度、版本与hash检查；动画方案不预留积分，确认方案后预留40；课件预留20，先看三页。
- 同一需求重复点击开始制作不会重复建任务。每个执行保存独立输入快照和幂等键；当前应用会话内切换菜单后，首页对话与任务继续保留。刷新浏览器后的服务端对话恢复不在本次范围。切换企业、成员或退出登录会清理首页会话。
- “我的作品”的新建课件、新建动画分别进入独立制作页。作品卡片减少图片高度与内部留白，1440px桌面可一行四张，390px手机为两列。
- 仅有动画权限的成员不会在首页请求无权访问的课件教材/参考接口。
