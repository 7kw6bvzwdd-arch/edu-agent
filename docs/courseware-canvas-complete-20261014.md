# 课件画布完成报告 · 2026-10-14

本轮计划的画布编辑能力已经完成并应用到当前 8080/8000 服务，版本为 canvas-v3。刷新页面，从“我的作品”打开课件，在页面上点击“编辑画布”。

## 已完成的操作

| 操作 | 当前支持 |
| --- | --- |
| 直接编辑 | 标题、正文、课堂提问；新增文本框直接输入 |
| 新增对象 | 文本框、PNG/JPEG图片、矩形、椭圆、直线、箭头 |
| 文字样式 | 新增文本框字号、粗体、颜色、填充与文字对齐 |
| 图片 | 上传、压缩、替换、说明；调整尺寸保持原长宽比 |
| 尺寸和位置 | 拖动、方向键微调、角点等比例缩放；新增对象可数值调整位置及宽高 |
| 旋转 | 普通文字区域、图片与普通图形；按真实页面边界保护 |
| 整理画面 | Shift多选、六种对齐、横向/纵向均匀分布、图层列表、置顶/置底/上下移动 |
| 操作保护 | 锁定/解锁、复制新增对象、删除、撤销/重做，最多30步 |
| 辅助查看 | 网格、吸附、适应/125%/150%/200%视图缩放、390px手机布局 |
| 实际预览 | 更新实际预览；可开启编辑后自动预览，合并连续修改，单次排版串行执行 |
| 保存与导出 | 写入原有修订、生成实际预览与PPTX；导出当前作品前保存有效修改 |

数学坐标图、受力图、电路图、数据图表和公式保持原方向，可以整体移动和等比例缩放。曲线、坐标、受力方向及标签作为整体保留。页面标题须保留非空；正文、提问、公式和图示可以删除，新增对象可以删除和复制。

新增对象生成原生PPTX文本框、图片和图形，没有把整页截图作为导出内容。保存重新打开后沿用已保存位置、大小、旋转和图层，避免重复缩放或图片叠加。删除图片并保存后，图片数据从当前页面/当前PPTX移除；已存在的版本历史仍按项目原有保留规则处理。

## 使用与保存语义

1. 点击“编辑画布”，编辑或添加需要的对象。点击文字区域进入输入，Ctrl+Enter完成；Esc撤销本次输入。中文组合输入不会触发这些快捷键。
2. 需要核对实际排版时点击“更新实际预览”。自动预览默认关闭，勾选后在编辑停顿时更新，没有持续轮询。
3. 点击“保存画布及其他修改”，再下载PPTX。新增图片/图形和文字随修订一起保存。已完成作品可以使用原有版本历史恢复。

即时选框、新增对象和输入控件表示待保存修改；实际排版仍由Office截图确认。预览返回实际对象坐标，后续调整以该坐标为基准。排版期间再次编辑会丢弃过期截图，失败会保留当前输入，不生成额外作品或扣积分。临时预览保留原课件页序、页码、页数和默认版式，单页预览不会变成另一张封面。

手工输入超限、文字放不下或对象超出页面时拒绝保存并保留原版本，不自动删字、拆页或替教师重新制作。原自动生成过程继续原有自动修复。保存后沿用“改动页重新审核、其他页保留审核”的规则。版本冲突保留本地编辑，不能静默覆盖其他修订。

课堂演示的“显示实际PPT整页”使用已保存的画布结果；“逐步讲解”按教学内容展示，并提示两种视图的区别。没有把教师备注或答案自动放到学生画面。

## 本轮边界

每页最多24个新增对象。新增文本框最多600字、字号16至60；图片压缩到既有内嵌图片预算，整套图片数据受既有总量限制。撤销栈只在当前画布打开期间保留，保存后的恢复使用版本历史。

本轮完成现有课件工作台的画布范围，仍不包含图示内部曲线/受力箭头的任意拆分、图片裁剪、整段富文本混合样式、多人同时拖动协作。新增公式仍使用现有页面内容编辑入口。数学物理整课内容、教学适用性、模型审核质量和整课速度需沿用后续独立验收，不能用本轮固定样例替代。
