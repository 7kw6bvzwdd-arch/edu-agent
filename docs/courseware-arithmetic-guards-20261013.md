# 确定性算术与审核依据 · 2026-10-13

状态：实现、局部验收和候选构建完成，未部署。当前正式服务继续使用已验收的旧二进制。本轮不应用上轮仍有漏检和误报的扩大审核候选。

## 已处理的实际问题

- 已有审核响应曾写出 `10000/10=1000000`。非阻塞建议也可能包含错误知识，不能只检查最终严重程度。
- 旧体积倍率规则从“未换算、直接代入SI”推断一定放大，缺少公式边界。密度公式把体积放在分母，不能套用浮力公式的倍率方向。
- 明确的 `800×10×0.001=9 N` 原先依赖模型发现。现在程序得到8，并输出同页修复依据。

## 实现范围

`courseware_arithmetic.go` 使用Go标准语法解析器和精确有理数计算，只处理明确数字四则运算等式及等式链。支持小数、负数、括号、乘除和运算顺序；不执行输入。检查当前页标题、问题、公式、要点、教师备注、答案，以及表格和教学图解的文字。它只识别错误并交给已有的局部自动修复，不猜题设、不直接覆写数据。

变量、幂、TeX分式、含单位的操作数、百分数、近似表达及不明确片段不作局部截取验算。循环小数舍入和超出支持范围的表达仍交给内容审核；不声称完成通用代数、单位量纲或物理条件证明。明确标为错误示例/错解的算式可保留，纠正部分独立检查。数字算对不能替代教学审核与实际画面审核。

体积倍率规则进一步收窄：页面必须有支持的阿基米德公式 `F浮=ρ液gV排` 等明确等价写法，且声明cm³/mm³数值未换算而直接代入SI公式，才核对其放大倍率。密度/分母、未知公式及体积幂不作上述推断。范围不支持时继续模型审核，不伪装为程序验证成功。

审核员新给出的evidence、repair和专项checks.evidence也检查明确数字等式。object可能是被引用的原错误，因此不把引用本身当审核员的新主张。无论error或suggestion，发现新算错均走现有契约重查：同页最多复核一次，不触发正确页重做；第二次仍错时按审核不可用保存/恢复。调用仍受现有持久预算约束。
