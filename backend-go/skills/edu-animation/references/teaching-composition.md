# 教学构图指导 · edu-animation-v2

先确定本片要解决的一个问题：学生观察什么对象，看到什么变化，凭什么得到结论。每幕 intent 写具体观察任务，图形与动作承载解释，旁白引导注意；不把教师材料逐段转成文字列表。沿用教师确认的范围、开场、时长、代表幕和局部修改要求。

构图从内容选择：空间关系用位置与路径，结构性质用结构及局部变化，文本细读用原文与附着批注，历史过程用事件与明确方向，比较用相同条件下的对象。可采用单主体、双对象对照、局部放大、沿路径展开或逐步揭示；这些是可选方法，不是每片必备幕序。相邻幕有新的观察任务才调整构图，同一对象可以延续。

画面先有清晰主体，再有必要证据和标注。主体尺寸足以辨认，短标注靠近对应对象，引线必须指明真实关系；保留字幕与控制区空间。现有播放器的明亮配色及字体保持一致，强调色表示对象或关系，不靠满屏色块和边框制造层级。教学确需表格、关系链或时间线时可以使用现有组件，不按版式、装饰或图形数量评分。

动作要能说清教学用途：参数改变、路径移动、结构拆解、局部高亮、先预测再揭示。只用技术契约支持的动作，按句子锚点组织先后；内部图示动画须由 progress 驱动。对象淡入只负责入场，不能代替所讲的运动或机制。需要同时比较时保留对照条件，需要思考时显式安排 holds；以实际语音边界编译时间轴，不用无意义静默凑时长。

完整讲解放 narration；画中保留必要原文、公式、关键词和可回答的问题。文字按意义逐项出现并指向讲解对象；原文确实需要连读时可保留完整短句，不强制拆成卡片。先让学生看见证据，再用短语归纳。自然开场可带邀请观察的语气，数学符号写出口语读法，不添加未支持的情绪或 SSML 字段。

提交前自查：遮住旁白，画面仍能辨认本幕关键对象；沿关键句前后取帧，能看到与解释一致的变化；回跳到同一时间得到同一状态。示意结构、非比例和条件限制明确标注；没有依据的知识与来源不能补成确定事实。仅修改指定幕时保留其他幕，审核失效仍按既有依赖与构建 hash 处理。

从 manim-video 蒸馏：先定学生原有误解、证据变化和理解转折。构建结构时让组成部分逐步出现，不能把完整结构旋转当作构建；比较时保持基准与语义颜色，学生必须看见差别。每句只引导当前观察重点，动作完成后保留观察时间。需要内部对象跟句时用 scene.actions 的 sentence 指向本幕句子，按实际语音起点触发；其 start_ms 仅为独立GIF/PPT预览的回退排程，不叠加到句子起点。视频该动作长度不超过对应句子时长。

从 frontend-slides 蒸馏：整幕在一个有边界的视口中完成，不滚动，不以小字解决容量问题。优先删掉重复讲解、缩短标注，确需新观察任务才拆幕；未经确认不擅自改变教师要求。主体、标注、字幕各留空间，禁止每幕机械套用“左模型右五条结论”。多个可比较科学对象放入同一个 scene 的内部画布，位置、大小和局部动作服从问题，不预设固定槽位。

保持明亮课堂风格和中文可读字体，不继承上游强制暗底、等宽字体、纯抽象装饰、每幕换色或统一元素数量。不执行模型生成的Python/HTML，不自动安装Manim，不改变现有语音供应商。渲染通过仅代表技术可播放；仍须检查实际帧的知识表达、逐句动作、停顿与倒退复现。
