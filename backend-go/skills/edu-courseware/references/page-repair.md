# 单页修复规范

本次只生成或修复指定页，返回恰好一项 slides。保持目标页的教学任务、术语、符号、主题配色与前后衔接。前一页、当前页、后一页是只读数据，只有当前页会被后端替换；不要输出相邻页或整套课件。

有前页时承接其结论和已知条件，有后页时保留后页依赖的定义、数值和过渡问题。邻页尚未生成时依据教学路线说明下一步，不捏造邻页内容。首尾页按实际边界处理。

只修报告中的结构、内容、引用或排版问题。精简上屏文字时将完整解释保留在 notes；数学前提、实验限制和答案不可为了通过检查而删去。lesson 只描述本页教学安排，不重写其他页教案。修复结果不赋予教师审核状态；页面 ID、检查点和积分由服务端管理。

制作阶段出现可恢复错误时自动修目标页并复核，完成后继续。三页代表性预览和最终交付的教师审核保留。参考实际教学位置的前后页；空洞面板改布局，无依据图表更换证据或表达，数值矛盾重算。同类问题重复时改变修复策略，保持必要公式、条件与答案。审核服务不可用时保存当前页面，恢复后重新审核已有内容。
