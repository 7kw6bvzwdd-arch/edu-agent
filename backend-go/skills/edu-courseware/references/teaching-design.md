# 教学与视觉规范

内容规划：根据实际学科、学习阶段、教材和已确认目标安排教学路线，不预设年级、教材、45分钟或固定页数。语文使用文本细读、意象、朗读和表达；外语使用语境、语言示范、对话和运用；历史使用史料、时序、因果和论证；其他学科围绕实际知识与实践任务。理科可采用问题、概念、证据、推理与练习，不能向其他学科强套实验或计算。每页一个明确任务，前页结论成为后页学习的起点；顺序根据课堂需求调整。整课路线只列用途，页面正文仅生成本次指定的页面。

视觉规划：沿用选定 theme 的配色、字体和层级；教学内容决定 layout，使用项目现有 cover/concept/steps/comparison/example/exercise/summary。封面清晰呈现核心问题与收获；正文页突出一个结论或问题。相同内容可沿用版式，不为变化强行切换布局。

上屏只放课堂需要看到的问题、条件、关键证据和简短结论。详细推导、讲解、评分点及练习答案写 notes；不以最低字数凑页，不靠缩小字体塞内容。每页一个主要学习任务，按实际工具能力组合必要的图形、图片或表格，建立主次关系。

比较数值用 chart，精确数据用 table，关系、过程或结构用 figure/diagram。图表单位、数量关系、图示文字与讲解一致；示意数据标明非实测。来源只引用已提供且确实支持内容的资料，缺乏依据时注明待核验。图片需有可核验出处；不虚构网址，不默认生成图片替代学科图解。

提交前核对条件、术语、公式、运算和答案；前页引入的符号在后页保持含义一致。质量提示用于改善表达，机器检查不构成事实认证。PPTX 渲染错误必须处理；每页能渲染后仍需教师审核。

参考风格沿用教师所选 theme 的颜色与字体，具体构图由教学任务和可用渲染能力决定。图表数量与版式数量不作为质量指标。预览选三页有实际讲解、图示或学习任务的代表页；教师审核通过后生成其余页面。参考方式依据内容、参考顺序、参考风格分别处理；只依据已提供的文字与实际画面，不声称读过未提取图片。

以下函数要求仅在实际课题涉及一次函数时适用，不要求其他课题生成函数图。一次函数内容：明确y=kx+b中k≠0，k=0仅作为常函数对照；两点法解释选点理由、代入、描点、连接并延长，不能把图像当线段。以真实坐标图比较k的符号与增减性、相同b不同k的倾斜、相同k不同b的平移，说明比较陡峭程度必须使用相同坐标比例。象限判断需由升降与(0,b)推导，b=0单独说明。教材页码与作业编号只有来源提供才可引用。

学科示范或例题包含必要背景、具体任务、分析与结论；计算题还应包含已知条件与必要运算，notes保留完整推导、合理性检查、答案与评分点。题量按教学目标、课时和学生基础安排，区分必讲与拓展。图、解析式、取值表和备注使用同一组数值。

函数图像使用graph而不是类别line图，参数由数值表达式计算。示例：graph={title:"两点法：y=2x+3",x_min:-2,x_max:2,y_min:-2,y_max:6,series:[{k:2,b:3,mark_x:[0,1]}]}。坐标范围必须包含原点并容纳标注点，每轴跨度至少1，数值绝对值不超过1000，series为1–4条，mark_x每条最多2个横坐标。渲染器计算纵坐标、按真实比例绘制可编辑直线和点。多条直线用不同颜色并列比较；一页不与其他媒体混排。不要使用对象x/y点集、SVG、自由代码或未支持的plot字段。一次函数课件至少两页使用graph，其中一页应比较两条以上直线；表格、流程图补充推理而不能代替函数图像。
