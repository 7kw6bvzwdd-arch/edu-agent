# 教学构图共用原则 · edu-courseware-v5

教学内容决定构图。先明确学习对象、待解决问题、关键证据与学生任务，再在现有能力内选择原文批注、主体图示、对象对照、过程展开、数据图或表格。每页有清楚的视觉中心；比较任务可有两个平等对象，复杂关系可有必要的多个对象。上屏信息服务读图与判断，详细讲解、推导和答案留在 notes。

整课规划时，visual 写学生要观察、比较或推出什么及必需标注，不写空泛装饰指令；只规划用途，不提前生成页面全文。三页代表性预览覆盖核心讲解、适合该学科的证据表达和学生任务，保持真实教学位置。当前请求的输出结构与页数由对应技术契约指定。

theme 表达教师已选择的配色方向，不规定左右分栏、底部结论条或统一教学顺序。教学路线服从教师目标、实际学科、课时和已确认规划；layout 只记录教学用途。新页面由模型直接编写HTML/CSS/SVG，自主决定构图。相同对象可沿用表达，有新增学习任务再调整。教师明确选择的模板和参考风格优先。

保持文字可读和图示主体足够大；短标注靠近证据，不以重复框线或装饰占位凑画面。真实图片保留可追溯出处，数学和科学图示直接绘制，示意和按题设计算明确区分。多图比较按需要绘制所有对象，检查一一对应的标注及证据，不能声称画出了未出现的对象。

页面修复只替换指定页，保留已确认内容及前后依赖。渲染成功、截图检查和教师审核分别记录；不能把技术通过当作事实或课堂效果认证。

frontend-slides适配：一页在真实画布边界内完成，超出容量先压缩重复信息或在已批准页数内重排，不能缩小到投影不可读、裁掉关键证据或靠滚动展示。图文比较以证据为中心，自主选择全幅、对照或过程构图。保持PPTX交付、教师选定配色、中文字体与可编辑正文；HTML风格预设不强制接管课件格式。

manim-video适配：概念从可观察形状、空间关系或结构开始，再给符号和结论。需要解释过程时按组成部分及关键变化设计受控动作，思考问题在结果揭示之前。动画仅在解释变化时使用；稳定的比较证据可以静态呈现。细节留notes，不给每幅图强加文字列表、边框和无关装饰。实际PPTX须检查主体尺寸、完整边界和关键状态，不能以JSON有效代替版面验收。
