# 直接视觉创作规范 · 2026-10-21

此规范取代旧组件、固定槽位和禁止HTML的生成约束。旧作品可继续读取；所有新画面由模型直接编写页面代码。

从 manim-video 蒸馏：先确定学生的误解、观察对象和理解转折。用结构、数量、运动或关系的实际变化解释知识；淡入、旋转和文字出现只在有教学作用时使用。比较保留同一基准、坐标比例和语义颜色。图形近似与实测事实明确区分，不把渲染通过当学科认证。

从 frontend-slides 蒸馏：每页/幕在1280×720视口内完成，不滚动；留白和层级由教学任务决定，不套固定卡片或左右双栏。课堂投屏使用明亮配色、可读中文、短标注，详细讲解在备注或旁白。放不下时删重复信息，不能缩成不可读小字。真实图片必须来自教师或可核验检索，不编造照片、地图和引文。

从 hyperframes-animation 蒸馏：动画状态只由当前时间和实际句子cue决定，回跳必须复现；按句子安排变化、观察和思考，不依赖累计帧、随机数、墙钟、后台定时器。预览与导出使用同一源码、音频和时间轴。检查关键句前后帧，而不是只看首帧或标题。

课件仍需前置知识、清楚任务、可观察证据、逐步推理和达标检查。理科题设/单位/适用条件一致；文本、人文、语言课按实际目标组织，不强制计算或实验。完整练习条件和问题必须在画面可见，答案留在备注/教师答案字段。资料不够时说明待核验，不虚构教材适配。规划只规定教学用途和依赖，不指定渲染组件或坐标。

数值图形从同一组命名参数计算，先核对顶点、单位、方向、边界和数值，再完成视觉表达；不能在SVG中留下NaN、Infinity、越界数组索引或未完成推导的注释。正方形须四边等长且相邻边垂直；图中的长度和面积须与题设一致。动态读数从当前同一组未舍入参数计算，统一显示精度并用约号标明近似，不能混用整数物距和高精度像高造成可见矛盾。连续演示的每个中间状态都须满足所讲关系，例如透镜像距与像高由当前物距和焦距计算，不能分别线性插值两个端点来冒充物理规律。源码注释不输出思考草稿、未执行方案或占位图形。

模型直接写HTML/CSS/SVG/同步JavaScript；宿主负责隔离、音频、字幕、时间轴、审批、额度和文件交付。课件标记文字导出可编辑PPT文本，复杂图形导出背景图层，不能宣称全部图形可编辑。单页修改同步源码和元数据，确认绑定实际内容hash。
